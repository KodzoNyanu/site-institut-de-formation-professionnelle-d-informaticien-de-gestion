Images de fond du carrousel du hero (page d'accueil)
=====================================================

Fichiers en place (référencés par index.html) :

  cpne.webp    -> diapo 2 « Une pédagogie par compétences… »
                  Vue aérienne du bâtiment CPNE, recadrée pour retirer le
                  bandeau/logo/menu du site d'origine (1918 x 522 px).

  campus.png   -> diapo 3 « Rentrée ouverte »
                  Salle informatique (photo de banque d'images).

Pour remplacer une image plus tard :
- Garder le MÊME nom de fichier (sinon adapter index.html).
- Format paysage, idéalement 1600 x 900 px ou plus.
- Si une image manque, la diapo reste sur fond noir (le texte reste lisible) —
  rien ne casse.
- Après remplacement : git add media/, git commit, git push
  (le déploiement Vercel + GitHub Pages se met à jour automatiquement).
